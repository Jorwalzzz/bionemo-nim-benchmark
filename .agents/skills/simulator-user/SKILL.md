   - Injects impatient user patterns: rapid multi-clicks, rapid viewport resizing, double-submission race conditions, and cancelled in-flight requests to expose unhandled frontend edge cases.

   - Injects simulated 3G network latency, packet jitter, and random HTTP 500 error spikes to verify that UI components display non-blocking skeleton loaders and resilient error toasts.
