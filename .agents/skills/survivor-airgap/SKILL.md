## 1. Prime Doctrines & Air-Gap Axioms

1. **Zero-Cloud Airgap Hermeticity**:
   - Every core computational capability (RDKit valence sanitization, data caching, 3D molecule viewing, benchmark charting) must run smoothly with network interfaces severed and zero outbound HTTP requests.
2. **Bit-Identical Mock Replays**:
   - Maintains verified, zero-dependency offline mock fixtures (`--mock`) for NVIDIA NIM models (ESM-2, ESMFold, DiffDock). CI/CD and local development must never fail due to API token exhaustion, network jitter, or remote 503 outages.
3. **Atomic Cold-Storage Snapshotting**:
   - Enforces automated, compact local state persistence (SQLite, Parquet, zstandard) to protect against unhandled OS shutdowns, container crashes, or hardware reboots.
4. **Self-Healing Fallback Replay**:
   - If remote inference endpoints encounter HTTP 429 (Rate Limit) or 503 errors, automatically reroutes the pipeline to local cached fixtures without terminating execution.
