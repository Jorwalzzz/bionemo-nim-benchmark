Logarithmic latency comparison spanning from sub-100ms token PLM embeddings to 3-minute multi-domain macromolecular polymer folding. Every metric represents the mean of n=5 warm container executions with strict output parity.

METHODOLOGY & HARDWARE CALIBRATION SPECIFICATION [ Click to expand / collapse ]
GPU Environment: NVIDIA H100 80GB SXM5 GPU (SXM5 socket, 700W peak active draw) running official NVIDIA container images (nvcr.io/nim/*) compiled with TensorRT-LLM and TensorRT FP16/FP8 execution engines.
CPU Baseline: AMD EPYC 7763 64-core server processor. Strict hardware isolation enforced by pinning 16 physical cores using numactl -C 0-15 to eliminate hyper-threading noise.
Statistical Rigor: Warm container execution (cold start omitted) over n=5 consecutive runs; reported latency is the arithmetic mean. Inter-run coefficient of variation (CV) < 2.4%.
Biological Validation: Output embeddings validated via Cosine Similarity (≥ 0.9996). 3D coordinates aligned with TM-align and PyMOL validating Cα RMSD (≤ 0.51 Å).
