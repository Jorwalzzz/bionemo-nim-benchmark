2. Interactive Slash Commands (Chat UI)

/plan Blueprint
Creates an interactive, step-by-step blueprint before touching any code. Avoids circular work.
/goal Autonomous Loop
Enables persistent, multi-hour execution loops that do not stop until the objective is 100% complete.
/grill-me Interview
Agent acts as a Staff Engineer, questioning you on edge cases and constraints before coding starts.
/learn Memory
Saves corrected behaviors, user rules, and workflows into persistent memory across all future sessions.
/schedule Timer / Cron
Schedules one-shot timers or recurring cron triggers for background checks without busy-waiting.

3. Core BioNeMo Tools

bionemo_query_diffdock Docking
Performs generative molecular docking between protein targets and small-molecule ligands.
bionemo_query_esmfold 3D Structure
Predicts 3D atomic coordinates (.pdb) with pLDDT confidence scores from raw amino acid sequences.
bionemo_query_esm2_embedding Embeddings
Extracts high-dimensional protein language representations for downstream ML or variant analysis.
bionemo_sanitize_smiles RDKit
Sanitizes ligand SMILES strings with explicit RDKit valence, charge, and aromaticity verification.
bionemo_validate_sequence FASTA
Validates protein sequences against the 20 canonical IUPAC amino acid residues.
bionemo_fetch_rcsb_pdb PDB
Fetches, cleans, and strips water/heteroatoms from experimental crystal structures (e.g. 6LU7, 1HSG).
bionemo_run_benchmark Profiling
Profiles NIM inference latency, throughput, speedup multipliers, and generates 300 DPI publication plots.
